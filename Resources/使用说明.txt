ChatGPT Proxy 2.0

首次使用：
1. 右键 ChatGPT-Proxy-2.0-Universal.pkg，选择“打开”并完成安装。安装器会同时安装 ChatGPT Proxy 和 ProxyBridge。
2. 打开 ChatGPT Proxy，点击“首次配置”。
3. 打开 ProxyBridge，并按 macOS 提示允许网络扩展。
4. 回到启动器，使用“自动导入并启用”安装 ChatGPT Only 专用配置。
5. 确认本机代理软件已启动。默认 SOCKS5/mixed 端口为 7890。
6. 点击“启动 ChatGPT”。

该工具不修改 macOS 系统代理。ProxyBridge 配置匹配 OpenAI 官方桌面相关 bundle；其他应用保持直连。

主窗口中的“打开 .codex”可打开当前用户的 Codex 配置目录；目录不存在时会自动创建。

说明：ChatGPT Proxy 使用固定的内部中继 127.0.0.1:17890，并把流量转发至界面中填写的端口。
安装器不会自动批准 ProxyBridge 网络扩展；该授权必须由当前用户在 macOS 系统设置中完成。
