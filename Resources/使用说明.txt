ChatGPT Proxy 2.2.2

首次使用：
1. 解压 ChatGPT-Proxy-2.2.2-Universal.zip，将 ChatGPT Proxy.app 放入应用程序目录。
2. 打开 ChatGPT Proxy，确认本地 SOCKS5 代理已运行，并在设置中填写端口（默认 7890）。
3. ProxyBridge 缺失、损坏或版本不匹配时点击状态行“修复”。应用在线下载官方 4.1.0 安装包，校验后通过命令行安装；按系统提示完成管理员认证。
4. 按 macOS 提示允许网络扩展；代理就绪后点击“启动 ChatGPT”。

分发 ZIP 不含 ChatGPT、ProxyBridge 或依赖安装包。修复需联网，使用配置的本地代理；失败可重试。修复不会自动启动或重启 GPT。

启动器以当前用户托管 ProxyBridge 4.1.0 CLI；请勿同时打开 ProxyBridge 界面或另一个 CLI 实例。
启动 GPT 时会为该应用设置 SOCKS5 启动参数，以代理端解析网页请求域名；不修改系统 DNS，保留本机和局域网直连。
关闭窗口继续驻留；正常退出先停止 CLI 再停止本地中继。查看代理日志可定位启动错误。

该工具不修改 macOS 系统代理。ProxyBridge 配置匹配 OpenAI 桌面相关 bundle、内置 Codex 后台程序及 Sparkle 更新器。其他路径下的同名 Codex 程序和其他应用的 Sparkle 更新器也会走代理；通用工具进程（curl、git、Python 等）不在匹配列表中。本机及 192.168.*.* 的 TCP 连接保留直连，其余匹配的 TCP/UDP 连接通过代理。

主窗口中的“打开 .codex”可打开当前用户的 Codex 配置目录；目录不存在时会自动创建。

说明：ChatGPT Proxy 使用固定的内部中继 127.0.0.1:17890，并把流量转发至“设置 → 代理”中填写的端口。
安装器不会自动批准 ProxyBridge 网络扩展；该授权必须由当前用户在 macOS 系统设置中完成。


后台监控与自动切换：
- 打开应用即监控，关闭窗口后继续驻留菜单栏；菜单栏可暂停、恢复或退出，暂停状态会保存。
- 每秒通过配置的本地代理向 https://www.google.com/ 发送 HEAD 请求，要求 HTTP 200；请求失败、超时或延迟超过 800ms 即测速。
- 仅支持 Clash Party 全局模式。只在同订阅、同国家或地区内选择不超过 800ms 的最快节点；没有合格节点保持原选择。
- 成功切换后冷却 5 秒，并关闭经过原节点与 GLOBAL 的旧连接，促使应用重连。
- 无法确认节点来源或地区时不切换；规则／直连模式只监测、不自动切换。无需另开控制端口。
- 监控日志位于 ~/Library/Logs/ChatGPT Proxy/monitor.jsonl，超过 5MB 自动轮转。


主窗口齿轮、菜单栏“设置…”或 ⌘, 可打开设置窗口。“开机自启动”使用系统登录项注册，开启后在“系统设置 → 通用 → 登录项与扩展 → 登录时打开”中显示 ChatGPT Proxy。登录启动仅驻留菜单栏；手动启动显示主窗口。首次安装默认不注册，状态以系统实际设置为准。
