ChatGPT Proxy 2.2.3

首次使用：
1. 解压 ChatGPT-Proxy-2.2.3-Universal.zip，将 ChatGPT Proxy.app 放入应用程序目录。
2. 打开 ChatGPT Proxy，确认本地 SOCKS5 代理已运行，并在设置中填写端口（默认 7890）。
3. ProxyBridge 缺失、损坏或版本不匹配时点击状态行“修复”。应用在线下载官方 4.1.1 安装包，校验后通过命令行安装；按系统提示完成管理员认证。
4. 按 macOS 提示允许网络扩展；代理就绪后点击“启动 ChatGPT”。

分发 ZIP 不含 ChatGPT、ProxyBridge 或依赖安装包。修复需联网，使用配置的本地代理；失败可重试。修复不会自动启动或重启 GPT。

启动器以当前用户托管 ProxyBridge 4.1.1 CLI；请勿同时打开 ProxyBridge 界面或另一个 CLI 实例。
启动 GPT 时会为该应用设置 SOCKS5 启动参数，并为原生 Codex 子进程设置大小写 HTTP_PROXY、HTTPS_PROXY 和 ALL_PROXY，统一指向 socks5h://127.0.0.1:17890。启动前还会启用系统 DNS 保护：首次需管理员认证安装辅助服务，系统 DNS 和 Clash 普通解析均经 GLOBAL 节点请求 DoH。大小写 NO_PROXY 保留本机和 192.168.0.0/16 直连；不修改用户的 Codex 配置。
更新启动器后，请通过它重新启动 ChatGPT，以应用原生代理设置并解决 workspace routing discovery timed out。
关闭窗口继续驻留；正常退出先停止 CLI 再停止本地中继。查看代理日志可定位启动错误。

该工具不修改 macOS 系统代理。ProxyBridge 配置匹配 OpenAI 桌面相关 bundle、内置 Codex 后台程序及 Sparkle 更新器。其他路径下的同名 Codex 程序和其他应用的 Sparkle 更新器也会走代理；通用工具进程（curl、git、Python 等）不在匹配列表中。本机及 192.168.*.* 的 TCP 连接保留直连，其他原生 IPv6 TCP 阻断，其余匹配的 TCP/UDP 连接通过代理。

“启用 DNS / IPv4 保护”会临时关闭共用 Clash 的 IPv6 和 AAAA 解析，节点及订阅覆盖强制使用 IPv4；其他使用该 Clash 实例的应用也受影响。启用时现有 Clash 连接会重建，已经打开的 GPT 会自动重启。UDP 经 IPv4 代理隧道保留语音功能；远端节点访问网站的地址族保持原样。macOS IPv6 和 ::1 本地 DNS 保留。恢复、退出或故障后还原原配置；恢复后保护关闭。

主窗口中的“打开 .codex”可打开当前用户的 Codex 配置目录；目录不存在时会自动创建。

说明：ChatGPT Proxy 使用固定的内部中继 127.0.0.1:17890，并把流量转发至“设置 → 代理”中填写的端口。
安装器不会自动批准 ProxyBridge 网络扩展；该授权必须由当前用户在 macOS 系统设置中完成。


启动前检测通过配置的本地 SOCKS5 代理检查 UDP Associate，并向 https://chatgpt.com/backend-api/codex/models 发送一次无凭据请求；HTTP 401 表示接口可达且要求认证。不再查询出口地区或按 CN 地区拦截。检测仅验证网络可达及连接保持情况，不验证账号、额度或模型会话。

后台监控与自动切换：
- 打开应用即监控，关闭窗口后继续驻留菜单栏；菜单栏可暂停、恢复或退出，暂停状态会保存。
- 持续复用一条 TCP/TLS 连接，每 2 秒向上述 Codex 地址发送无凭据 HTTP/1.1 心跳，要求 HTTP 401。初次建链最多等待 10 秒，之后连续 10 秒无有效响应、连接关闭、TLS 错误或异常状态均判为失败；不使用登录凭据，不跟随重定向，保留 TLS 证书校验，由代理端解析域名。
- 同一连接从首个有效心跳起考核 60 秒。未满 60 秒断线计一次，1 秒后重连；连续两次才启动节点恢复。有效心跳确认已满 60 秒即清零失败计数，继续维持原连接。底层重连重新计时；维持阶段不因延迟超过 800 ms 切换。
- 仅支持 Clash Party 全局模式，恢复始终限制在同一订阅内。先测试当前地区，再按已勾选备用地区从上到下尝试；每地区最多并发测速 4 个节点，每轮每节点只测一次。使用同一 Codex 地址、预期状态 401，测速期限 10 秒；仅延迟大于 0 且不超过 800 ms 的候选入选，并按延迟、节点名排序。
- 首轮跳过触发恢复的节点。按排名临时选中候选，确认实际选择并清理上一节点的旧 GLOBAL 连接，再用全新连接验收。候选保持满 10 秒且收到有效心跳才接受；中途失败继续尝试下一节点或地区。验收通过的同一连接继续进入 60 秒考核，已验证的 10 秒计入时长。
- 两次节点选择写入间隔至少 5 秒。全部候选失败后保留控制器实际选择，按 2、4、8、16、30 秒退避重试，之后保持 30 秒；后续轮允许重新评估失败节点。
- 设置可勾选备用地区并调整优先级，自动保存；新增地区默认不勾选，暂时缺失的地区保留并跳过。手动换节点、订阅或配置变化、改端口、暂停及系统唤醒时关闭旧观察并重新计时；健康时不会主动回切。
- 无法确认节点来源或地区时不切换；规则／直连模式或控制接口不可用时仍监测 Codex。无需另开控制端口。
- 主窗口和菜单栏显示心跳延迟、连接已验证时长、失败计数、候选验收进度和上次断线原因；恢复失败显示下次重试等待时间。
- 监控日志位于 ~/Library/Logs/ChatGPT Proxy/monitor.jsonl，超过 5MB 自动轮转。正常退出等待监控连接释放。


主窗口齿轮、菜单栏“设置…”或 ⌘, 可打开设置窗口。“开机自启动”使用系统登录项注册，开启后在“系统设置 → 通用 → 登录项与扩展 → 登录时打开”中显示 ChatGPT Proxy。登录启动仅驻留菜单栏；手动启动显示主窗口。首次安装默认不注册，状态以系统实际设置为准。
