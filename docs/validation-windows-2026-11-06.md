# Windows 与共享核心验收（2026-11-06）

## 实现范围

共用业务逻辑采用 Rust，通过版本化 C ABI 接入 macOS SwiftUI 与 Windows WPF。共享内容包括 SOCKS 中继与探测、单连接 TLS 心跳、自动切换工作流、地区／订阅策略、Clash 请求协议、ProxyBridge 规则与输出解析、双栈 DNS 转发、配置变换和可恢复 DNS 事务。进程启动、系统认证、窗口、注册表、服务、PF/WFP 等操作由平台适配层执行。

Windows 安装布局将 WPF 与服务的独立 .NET 运行时分开，服务运行于 LocalSystem，绑定安装用户 SID。IPC 拒绝远程连接，并校验客户端 SID／程序路径及服务 SCM PID。恢复记录只允许 SYSTEM 与 Administrators 访问。读取 Clash 配置与订阅文件时使用实际 Clash 进程令牌，避免通过 SYSTEM 服务扩大文件读取权限。安装升级及卸载均先要求成功恢复 DNS；未知记录版本保留并阻止覆盖。

## 修复的联调问题

1. Windows UDP 在客户端提前关闭后，把 ICMP port-unreachable 作为 WSAECONNRESET 返回给监听器。原实现退出监听任务，继而关闭四个 DNS 入口。先用真实 UDP 用例复现，再将单个数据报的 reset/refused 错误与监听器故障区分；回归通过。
2. 直接启动 WindowsApps 下的 ChatGPT 可执行文件会丢失 MSIX 身份。改为应用激活管理器，并校验官方包 family 与运行进程身份。
3. ChatGPT 的窗口关闭会保留后台进程。适配层请求其 File > Quit 快捷键，验证前台目标，等待正常结束；超时仍回滚，不强制终止应用。
4. WPF 与服务合并发布会用服务的 `WindowsBase.dll` 覆盖 WPF 实现。安装包将两个发布目录隔离。
5. PowerShell 5 的 JSON 数组输出、网卡 GUID 类型比较，以及命名管道 SYSTEM 权限均与最初实现假设不同，已通过远程真实运行修正。
6. Inno 初始化卸载阶段会调用 32 位 PowerShell，`ProgramFiles` 指向 x86 目录。固定使用 `ProgramW6432` 定位 x64 安装，避免清理登录项时读错路径。
7. 恢复完成与暂停时清理旧监控状态；候选仅向 Windows UI 传递地区计数，避免大订阅使 IPC 状态超过帧上限。
